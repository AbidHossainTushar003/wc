# USER_TEST.md — Shop Owner Testing Checklist

Follow this checklist with the phone in hand:
1. **Morning Routine:**
   - Launch the app and sign in with the owner-provisioned username, password, and current six-digit authenticator code.
   - Review Executive Dashboard KPI cards (Gross Revenue, Orders, Low Stock).
2. **Order Fulfillment:**
   - Open Orders screen, filter by `Pending`.
   - Tap an order to view customer details, tap WhatsApp/Call buttons to verify COD.
   - Advance order status from `Pending` → `Processing` → `Shipped` → `Delivered`.
3. **Catalog & Inventory:**
   - Open Products screen, tap `+ Add` to add a new item with camera/gallery photos.
   - Edit an existing product's price or stock quantity.
   - In Inventory, try the `−1`, `+1`, and `+5` controls. Confirm each update refreshes the displayed stock, controls cannot be tapped repeatedly while a request is pending, and a failed request displays an error instead of appearing successful.
   - Confirm `−1` is disabled at zero stock and the stock controls have clear screen-reader labels and comfortable touch targets.
4. **End-of-Day Review:**
   - Check Reports screen for sales summary and cash reconciliation.
   - Access Settings to verify store profile and API connection.
